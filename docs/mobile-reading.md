# 手机端阅读与记录

手机窄屏自动使用阅读工作台；电脑保留自由画布。触控手机横屏时也优先使用阅读界面。

## 内容结构

文件夹 → 文档 → 章节 → 一个或多个原有 Block。

章节的标题、顺序和 Block 归属保存在页面的 `chapters` 字段中，云端持久化。内容仍然来自原有 Block；手机编辑正文时不改变已有卡片的坐标、尺寸或父子关系。

旧文档首次打开时，根据原有分组、标题及父子层级生成阅读目录。用户可在「整理章节」中修改标题、排序、合并归属或新增章节。没有分配的内容会出现在「未分章内容」，不会被隐藏。

## 已接入的操作

- 文档列表、搜索、文件夹浏览和继续阅读。
- 章节聚焦阅读、前后章节切换。
- 文本、引用、待办正文、代码和公式轻编辑。
- 大表格按记录展开，编辑时一次处理一条记录；导图按树形目录查看。
- 章节内追加正文；已有画布对象保持原位，新内容放在现有画布下方。
- 「＋」随手记。记录保存为收件箱文档中的真实文本 Block，可在电脑端继续整理。
- 未提交的文字草稿按账号和内容编号暂存在本机；保存失败时保留待同步副本，提供重试入口。
- 保存请求携带页面版本。发生冲突时保留本机修改并提示合并，不自动覆盖云端内容。
- 访客可阅读示例，编辑和记录需要登录。

## 范围

本轮以阅读、轻编辑和文字记录为主。媒体和白板提供阅读预览，复杂画布布局、媒体上传及 AI 编排继续使用电脑端。章节整理通过手机入口完成，电脑目录同步会保留其云端版本。

## 验证

自动测试覆盖多 Block 章节、独立阅读顺序、残缺层级保护、章节持久化与访问边界、正文编辑、坐标保持、版本冲突保留草稿、随手记及跨端目录同步。

本地浏览器验收使用独立数据库文件及关闭云连接的启动环境，避免写入线上数据。`BLOCKOS_DB_PATH` 可指定本地验收数据库文件；正式运行仍使用原有默认配置。
