# BlockOS 图标素材

用户于 2026-10-21 选定的蓝色立体 B 图标。

- blockos-source.png：用户上传原图，1254 × 1254，逐字节保留。
- blockos-icon-{size}.png：16、32、48、64、180、192、256、512 像素版本。
- src/app/favicon.ico：包含 16、32、48、256 像素的 PNG 编码图标。
- public/favicon.svg：兼容旧链接，内嵌同一份选定图标。

运行 node scripts/build-brand-assets.mjs 可从保留原图重新生成全部尺寸。仅做尺寸适配，不重新设计图形。

已用于登录页、启动页、桌面侧栏与顶栏、移动端及浏览器标签页。180 像素版本用于 Apple 主屏图标。
